# 3.1 통합 점검

확인한 기준 커밋: 친구의 가호 기능 `5e460385e2eb00899500613ccf5d1cc5665286ea`, 단어장 추가 `f03b25e83b2f4be660df80da35818860adde910e`.

확인 당시 main에는 두 변경이 함께 존재했다. 별도 브랜치의 가호·인트로·오프라인 변경도 main의 조상 커밋에 포함되어 있었다. 친구의 가호 편집기·파일 저장/불러오기·테마 저장·배경·인트로·동전·갑툭튀 코드는 그대로 유지했다. 오래된 브랜치 전체로 현재 파일을 덮어쓰지 않았다.

브라우저 통합 검증:

- 단어장 카드 확인 중 가호를 거둬도 학습 화면과 카드 상태를 유지한다.
- 가호를 거두거나 사용자 가호를 선택하면 기존 인트로가 다시 재생된다.
- 사용자 가호의 동전 문구와 배경 사진이 반영된다. 과목 선택 카드에는 사용자 카드 사진이 적용된다.
- 배포 형식 `/johamin/`의 빌드에서 서비스 워커 설치 및 업데이트 확인이 작동한다.
- 첫 온라인 접속 후 브라우저를 오프라인으로 전환하고 새로고침해도 박상영T 원문 단어장과 정의 입력 연습이 열린다.

추가 개선:

- 온라인/오프라인 상태와 업데이트 확인 버튼. 새 버전 준비 시 사용자가 직접 적용한다. 작성 중인 답안이 있으면 새로고침 전 확인한다.
- 외부 글꼴·영상의 로딩 완료를 기다리지 않고 서비스 워커 등록을 시작한다.
- 앱 코드·스타일·아이콘·시작 페이지를 우선 저장한다. 선택적 이미지/영상 일부의 다운로드 실패가 오프라인 학습 전체의 설치를 막지 않도록 한다. 내려받지 못한 미디어는 다음 온라인 요청에서 다시 저장한다.
- 서비스 워커 코드 변경도 빌드 캐시 버전에 반영한다.
- 전체 기존 데이터/게임/가호/단어장 테스트 및 오프라인 설치 회귀 테스트 통과.

오프라인은 첫 온라인 접속에서 저장된 자료를 대상으로 한다. 인터넷의 외부 참고 링크와 데이터베이스의 새 자료는 연결이 필요하다. 사용자 가호 사진과 학습 기록은 기존처럼 해당 기기에 저장된다.
