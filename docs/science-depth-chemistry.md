# 생명 심화·화학 추가 — 3.5.0

## 화면과 분량

기존 디자인, 가호, 카드 패, 원문 단어장, 오답 기록은 유지한다.

- 과학 → 생물 → 박상영T: 새 심화 객관식 64문제·서술형 12문제, 개념 6단원.
- 과학 → 생물 → 조용민T: 전사·가공·번역 심화 객관식 18문제·서술형 3문제, 개념 2단원. 오페론과 이후 범위는 제외한다.
- 과학 → 물리·화학 → 화학: 개념 8단원·객관식 76문제·서술형 13문제.
- 화학 → 직접 연습하기: 강산·강염기 적정 곡선, 완충 성분 변화, 5% 근사 검토.

과학 메뉴에서 세 방향과 뒤로 이동을 유지하기 위해 물리·화학을 한 하위 메뉴로 묶었다. 각 문제는 단원 선택으로 따로 연습할 수 있고 개념에서 관련 문제로 이동한다.

## 사실 확인과 범위 주의

- 필기 2쪽의 프로젝트 표기는 HGP다. 사용자 메시지의 HGS를 새 용어로 추가하지 않았다.
- 멘델은 1865년 발표·1866년 논문 출판을 구분한다.
- 필기 1쪽에는 모건 옆에 1905가 있지만 흰눈 초파리 성연관 결과 논문은 1910년이다. 새 문항은 실제 발표 연도로 쓰고 차이를 설명한다. 선생님의 시험 연도 표기는 수업에서 확인할 수 있도록 표시했다.
- GWAS 유의성은 효과 크기·인과성·개인 확진과 다르다. p<5×10⁻⁸은 해당 문항에 명시한 기준이다.
- 키아즈마는 교차의 결과로 관찰되는 연결 부위이다. 교차는 비자매염색분체 사이에서 기존 조합을 바꾸며 새 변이를 만드는 돌연변이와 구별한다.
- 대표 핵형과 증후군 연결을 제시하되 모든 환자가 한 핵형이라는 일반화는 피한다.
- 코발트 평형의 희석은 물 활동도를 일정하게 근사하고 이온 농도 변화로 설명한다. 물 농도 항 자체가 K를 바꾼다고 설명하지 않는다.
- 계산에는 Kp를 사용하지 않는다. 5% 규칙은 C−x≈C의 타당성 검사이며 다른 근사의 검증을 대신하지 않는다.
- 적정 모형은 25℃, 강한 단양성자 산·강염기, 이상 활동도, 부피 가산을 가정한다. 물의 이온화를 포함해 중화점 부근 계산 불연속을 피했다. 약산 적정이나 실제 측정 데이터로 오인하지 않도록 화면에 조건을 표시한다.
- 완충 모형은 강산·강염기를 먼저 소비한 뒤의 몰수만 표시한다. 완충 성분이 소진되면 pH 근사를 제시하지 않는다.

## DB 반영 — 병합 전 필수

현재 DB 쓰기 연결이 없어 이 작업에서 DB를 수정하지 않았다. AGENTS.md 3-2에 따라 `db/science-depth-release.sql`을 Supabase SQL Editor에서 실행·검증한 뒤에만 병합한다.

1. PR 검사가 통과했는지 확인한다.
2. SQL 전체를 한 번에 실행한다. 새 화학 덱과 186개 문항만 INSERT한다. 기존 카드에 UPDATE·DELETE를 하지 않는다.
3. 같은 신규 ID에 내용이 다르거나 새 화학 덱이 다른 내용으로 이미 있으면 트랜잭션이 중단된다. 충돌 내용을 먼저 검토한다.
4. 마지막 조회 결과가 박상영T 객관식64·서술형12, 조용민T 객관식18·서술형3, 화학 객관식76·서술형13인지 확인한다.
5. PR에 DB 반영 완료를 남기고 병합한다. GitHub Pages 배포 성공을 확인한다.

전체 `db/seed.sql` 대신 이번 추가 전용 SQL을 사용한다. 기존 DB 덱은 코드보다 먼저 읽혀서 DB 반영 전에는 새 생명 문제가 보이지 않는다.

2026-10-11 조회 당시 기존 DB에는 1143개 카드가 있었고, main의 코드 사본과 국어 뉴욕제과점의 7개 카드가 이미 달랐다. 이 작업에서는 어느 쪽도 덮어쓰지 않는다. 별도의 동기화 작업으로 현재 DB 교정이 코드에 보존되는지 확인할 필요가 있다.
