# 3.5.1 학습 연습

기존 main의 카드와 DB에서 수정된 내용은 보존하고 미게시 작업을 재구현했다.

- 11개 자료 보유 파트: 기존 근거를 사용한 서술형 변형 130개, 단답형 변형 152개. 자료 없는 고전 시가는 준비 중으로 유지한다.
- 신규 생명·화학 적용 객관식 52개: 키아즈마·연관 계산, GWAS, 연혁, 비분리, 돌연변이, 농도 평형, 중화와 적정 오차, 가수분해와 완충.
- 단답형은 지정된 정답 하나와 비교한다. 공백·문장부호·일반 영문 대소문자는 무시하되 수식 부호·소수점·분수·유전자의 대소문자는 보존한다. 서술형은 근거를 보고 직접 채점한다.
- 단어장 세 기본 모드는 전체 22개로 즉시 시작한다. 복습·즐겨찾기 바로가기는 유지한다. 문장 배치 크기는 큰 조각/3낱말 단위/낱말 중 선택한다. 크기를 바꾸면 현재 용어의 배치만 다시 시작한다.
- 원문 정의와 기존 localStorage 키 및 학습 기록은 변경하지 않는다.

## DB 반영

PR #15에서 기존 생명·화학 186개가 이미 DB에 반영되었다. 따라서 이번 추가 SQL은 334개만 INSERT하고 기존 카드는 변경하지 않는다.

1. CI와 화면 검증 후 Supabase SQL Editor에서 db/study-practice-3.5.1.sql을 실행한다.
2. practice-short-/practice-written-/practice-depth- ID의 개수가 334개인지 확인한다.
3. DB 반영 후 PR을 병합하면 GitHub Pages가 배포된다.

SQL은 재실행해도 동일한 ID를 중복 생성하지 않는다. 전체 seed를 새 운영 DB에 덮어쓰지 않는다.

## 검증

- 필수 검사 26개 및 타입 검사·프로덕션 빌드 통과.
- Chrome에서 1440×900, 390×844 화면: 키보드 이동, 카드 스와이프, 전체 22개 시작, 조각 크기 전환·선택, 정의 채점과 기록 저장, 단답형 정답·오답, 가로 넘침 검사 통과.
- 운영 DB에 아직 적용하지 않은 추가 행은 최신 db/cards.json을 응답하는 테스트 대역으로 화면에서 검증했다. 운영 DB 적용 자체를 완료했다고 주장하지 않는다.
- 기존 카드 1329개가 내보낸 DB 사본에서 내용까지 동일한 것을 확인했다.
