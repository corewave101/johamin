# 황윤환T 시험 답쓰기 · 3.5.2

- 원본: 사용자가 지정한 행성우주과학 수정본 가로 59쪽 PDF. 내용 페이지 3~38쪽 및 명시적으로 포함 요청한 EM200 43~46쪽을 직접 대조했다. 표류법 39~41쪽, EM11 47~49쪽, 디지털 카메라 이후는 제외한다. 표지와 장 구분 페이지는 개념이 없다.
- 단답형 250개, 서술형 33개. 부품·규격·수치·조작 방향·원인·안전·조립 6단계·주의사항 5가지·EM200 정렬 4단계·실제 레티클을 포함한다.
- 공식 답 하나와 동의어를 비교하고 숫자 문제는 동등한 소수 표기를 허용한다. 서로 다른 부품이나 잘못된 수치는 오답이다. 서술형은 단계별 채점 기준으로 직접 체크한다. 자동 AI 채점은 아니다.
- 8단원 선택, 단답형 오답 복습, 이 기기 답안 자동 저장, 자료 그림 힌트를 지원한다. 그림은 정답 단서가 있으므로 접힌 상태로 시작한다.
- 수업자료의 연도·북극성 수치·구경비 표기를 따른다. 2021년 도해는 예시이며 실제 정렬은 관측 연도를 고려한다. 경도 보정은 자료에 상세 수식이 없으므로 수식을 만들어 넣지 않는다.

## 데이터와 배포

운영 DB 조회 시 총 1329개 카드, astronomy-hwang 서술형 0개였다. 기존 withLiveCards는 해당 덱에 DB 서술형이 없으면 코드의 서술형을 사용하므로 현 DB 응답에서도 시험 연습이 표시됨을 PC·폰에서 확인했다. 이 동작을 수정하거나 DB를 우회하지 않았다.

운영 DB 쓰기 권한/대시보드 연결이 제공되지 않아 새 283개는 아직 DB 미반영이다. db/hwang-exam-3.5.2.sql을 SQL Editor에서 실행하고 hwang_exam_rows=283을 확인해야 한다. 앞선 3.5.1의 334개도 조회 당시 미반영이므로 db/study-practice-3.5.1.sql 실행이 별도로 필요하다. 전체 seed.sql은 기존 운영 카드에 덮어쓰지 않는다. 코드·DB 반영 및 CI 확인 뒤 PR을 병합한다.
