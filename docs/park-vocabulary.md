# 박상영T 원문 단어장

박상영T 메뉴의 ‘원문 단어장’에서 교사용 정답지의 정의 22개를 따로 학습한다. 일반 개념·객관식·서술형 목록에서는 용어 전용 항목을 뺐다. 기존 문제 ID와 저장 기록을 지키려고 원래 문제 데이터는 지우지 않았다.

정의는 ‘유전학 용어 정리 활동지 정답지 (교사용)’의 ‘정의 및 설명 (정답)’ 열을 옮겼다. PDF의 지면 줄바꿈만 한 칸 공백으로 이었다. 교사용 원문 문구는 개념 설명이나 기존 문제 해설로 바꾸지 않는다.

## 메뉴 (3.2 베타)

박상영T의 모든 메뉴는 카드다. ↑ ← → 로 고르고 ↓ 는 언제나 ‘뒤로’(회색), Esc도 한 단계 뒤로. 방향키·카드 밀기·누르기가 모두 같은 동작이라 PC에서 방향키→마우스, 패드에서 밀기→누르기로 바꿔 잡을 일이 없다.

- 박상영T: ↑ 개념 정리 · ← 문제 풀기 · → 원문 단어장
- 문제 풀기: ↑ 객관식 전체 · ← 단원 골라 풀기(← → 로 단원 넘기기) · → 서술형 / 오답이 있으면 ‘오답만 다시’
- 서술형: ↑ 문장 배치로 풀기 · → 직접 써 보기
- 원문 단어장: ↑ 카드로 외우기 · ← 문장 배치 · → 쓰기 테스트 / 용어 목록·뜻 보고 용어 맞히기·객관식 22문제는 아래 작은 버튼

모든 연습은 고정 묶음에서 시작한다(무작위 5개 대신 같은 묶음을 반복해 외우기): 기본 용어 6 · 우열과 유전 법칙 4 · 유전 방식 5 · DNA 구조 4 · 돌연변이 3, 그리고 다시 볼 용어 · 즐겨찾기 · 전체 22개.

## 채점: 핵심어 부분 점수

- 용어마다 핵심어 2~5개(`data/park-vocabulary.ts`의 `keywords`). 쓴 핵심어 개수만큼 점수(예: 3 / 4). 순서·띄어쓰기·조사는 보지 않고, 같은 뜻의 말(같은 위치 = 같은 좌위)은 인정한다.
- 결과 화면에서 쓴 핵심어는 초록, 빠진 핵심어는 회색. 문구는 점수에 따라 ‘핵심어를 전부 썼어요!’ · ‘거의 다 왔어요’ 등.
- 정의를 글자까지 똑같이 쓰면(띄어쓰기만 무시) ‘원문 완벽 ✦’ 배지.
- XP: 용어당 하루 최대 10, 핵심어 비율만큼(3/4 → 8). 같은 날 더 잘 쓰면 차이만 더 받고, 같은 점수로는 다시 받지 않는다. 힌트(핵심어 첫 글자)를 보면 XP 없음.
- 핵심어를 전부 쓰면 ‘외움’으로 기록되고 1·3·7일 뒤 복습. 빠진 게 있으면 그 묶음 끝에 한 번 더 나오고 바로 복습 대상이 된다.
- 핵심어 목록은 내려받은 단어장 파일에도 들어간다.

## 문장 배치

정의(손으로 자른 3~4조각, 이어 붙이면 원문과 같음)와 서술형 모범답안(문장·연결어미 기준 자동 분할)을 조각으로 흩어 놓고 순서대로 쌓는다. 조각을 누르면 위 덱에 쌓이고, 쌓은 조각을 누르면 그 뒤까지 되돌아온다. PC는 숫자키로 고르고 Backspace로 되돌리며 Enter로 다음. 다 쌓으면 자리마다 ✓/✕를 보여 주고 틀린 자리부터 다시 놓거나 정답 순서를 볼 수 있다.
