# 박상영T 원문 단어장

박상영T 메뉴의 ‘원문 단어장’에서 교사용 정답지의 정의 22개를 별도로 학습한다. 일반 개념·객관식·서술형 목록에서는 용어 전용 항목을 제외했다. 기존 문제 ID와 저장 기록을 유지하기 위해 원래 문제 데이터는 삭제하지 않았다.

정의는 ‘유전학 용어 정리 활동지 정답지 (교사용)’의 ‘정의 및 설명 (정답)’ 열을 옮겼다. PDF의 지면 줄바꿈만 한 칸 공백으로 연결했다. 교사용 원문의 문구는 개념 설명이나 기존 문제 해설로 대체하지 않는다. 모든 22개 정의를 기존 원문 추출본과 대조했다.

- 카드 암기: 정의를 떠올린 뒤 뒤집어서 확인하고 어려운 카드를 한 번 더 본다.
- 원문 입력: 용어를 보고 정의 전체를 입력한다. 조사, 문장부호, 내부 공백까지 비교한다. 입력 앞뒤 공백과 한글 Unicode 조합 차이만 정규화한다.
- 보조 연습: 앞부분 힌트와 띄어쓰기 제외 옵션을 쓸 수 있다. 보조 연습 정답은 원문 성공이나 XP에 포함하지 않는다.
- 역방향 연습: 원문 정의를 보고 용어를 입력한다. 원문 정의 암기 성공 기록과 분리한다.
- 실전 테스트: 선택한 목록에서 최대 5개를 무작위 출제하고 힌트 없이 엄격하게 채점한다. 오답 재출제는 테스트를 마친 뒤 복습에서 한다.
- 복습: 원문 오류가 있는 용어와 즐겨찾기를 따로 모은다. 원문 입력 연습에서는 틀린 용어가 한 번 더 나온다.
- 학습 기록: 성공 후 1·3·7일 복습 예정일, 하루 용어별 10 XP, 하루 5개 목표, 연속 학습일을 기기에 저장한다. 반복 정답으로 같은 날 XP가 중복 지급되지 않는다. 정의가 바뀌면 이전 정의의 성공 기록은 새 정의에 적용되지 않는다.
- 원문 단어장: 전체 용어와 정의를 UTF-8 텍스트로 내려받는다.

단어장 카드에서 ‘기억했어요’를 누른 기록이나 객관식 정답은 원문 정의를 쓸 수 있다는 성공 기록으로 간주하지 않는다. 원문 비교 채점은 앱의 암기 연습 기준이며 실제 교사의 평가 결과를 자동 판정하는 기능은 아니다. 진행 기록은 해당 브라우저에 저장되며 입력 중인 답안은 화면을 나가면 초기화된다.
